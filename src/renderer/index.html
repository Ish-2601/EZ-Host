Servers

    Host a modded Minecraft server

    Pick any modpack from Modrinth. Java and the mod loader install automatically, and the server runs on this PC so friends can play even when you are not in game.

    New server

    Use a game profile you already play

    The server gets the same mods and mod loader as the profile, so your game matches it.

    Or pick a modpack from Modrinth

    Most modpacks want 4–8 GB. Leave enough for Windows and anything else you run.
    ⛏

    Mods that only change how the game looks (client-only) are left off the server automatically when Modrinth knows about them.

    Installing…
    Minecraft servers require agreeing to the Minecraft End User License Agreement.

    1. Server address

    Friends outside your home network can't use these addresses yet. A free playit.gg online address is the next feature.

    2. Get the same mods

    Each player's game must match the server exactly, or Minecraft shows a "Connection Lost" or "missing mod" error.

      How to import the pack in CurseForge
      1. Send the .zip to your friend (or use it yourself).
      2. In the CurseForge app, open Minecraft and click Create Custom Profile.
      3. Click Import at the top of that window and choose the .zip.
      4. Play from that new profile.

      3. Join in Minecraft

      1. Press Start above and wait until the status says running.
      2. Open Minecraft from the matching profile.
      3. Click Multiplayer, then Add Server.
      4. Paste the address from step 1 into Server Address and click Done.
      5. Double-click the server in the list to join.
