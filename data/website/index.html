Host game servers on your own PC.

EZ Host sets up and runs Minecraft and Project Zomboid servers for you, and gives your friends an address to join from anywhere. No commands, no router settings, no monthly bill.

Supported games

Two games, each with its own tools

Minecraft: Java Edition

Fabric, Forge, NeoForge, Quilt, Paper and plain vanilla. Host the profile you already play from CurseForge, Modrinth App or Prism, or pick any Modrinth modpack or .mrpack file.

  • Players, whitelist, OP, inventories with in-game item pictures
  • Live world map with chunk force-loading, and world pregeneration
  • Mods list with conflict checks; client-only mods left out automatically
  • Backups, schedules and automatic restarts

Project Zomboid (Build 42)

A dedicated server installed through Steam without a login. Start from the game's world presets, copy a server you host in game, and add your Steam Workshop collections.

  • Every server option and world rule, including the ones your mods add
  • The in-game map with players, plus item, vehicle and skill tools
  • Whitelist accounts, admin powers, world actions and mod-update restarts
  • Starts that survive deleted Workshop mods and Steam hiccups

Features

Made to be easy

Friends join from anywhere

Every server gets its own online address through playit.gg. The app shows exactly what friends need to type.

It says what's wrong

Startup progress, plain-language errors, and automatic retries instead of a wall of log text.

Right-click everything

Players, servers and mods all have right-click menus, so common jobs are one click.

Memory suggestions

EZ Host suggests how much memory a server needs from its mods and player count.

Make it yours

Three themes, your choice of accent colour, panel style, background, spacing and a status strip.

Your files stay yours

FAQ

Questions

Is it really free?

Yes. EZ Host is free and open source (MIT licence). playit.gg's free plan gives every server an address. Your friends still need to own the game.

Does my PC need to stay on?

Yes. The server runs on your PC, so friends can play while EZ Host is open and the server is started.

Where are my servers stored?

In %APPDATA%\self-host-mc\data. Uninstalling keeps them.

How much memory should I give a server?

EZ Host suggests an amount from your mods and players. A few mods need about 4 GB. Big modpacks, or Zomboid with hundreds of mods, need 8 to 12 GB.

My friend can't connect.

Open the server's Friends' setup tab. It shows the exact address and port, the game version and the mods they need.

Zomboid says playit.gg needs a verified email.

playit.gg only gives UDP addresses (which Zomboid uses) to accounts with a verified email. Verify it on playit.gg and press Try again.

Why does Windows warn me about the installer?

Windows warns about any new installer that doesn't have a paid code-signing certificate. EZ Host is free and open source, so it doesn't yet. EZ Host is applying for free code signing for open-source projects from SignPath.io, with a certificate from the SignPath Foundation. Until then, every release lists SHA-256 checksums you can check, and all of the code is on GitHub. Read the code signing policy.
